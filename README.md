# 知络 · AI 知识管理 Agent

把碎片知识转化为可检索、可关联、可复习的个人知识网络。

- 在线演示：https://mxr520.github.io/zhiluo/
- 定位：AI 产品经理复试原型（MVP Demo）
- 技术：纯前端单文件 SPA（HTML/CSS/JS），无后端，数据存 localStorage

## 功能
- 多源导入（文件 / 链接 / 截图 OCR / 语音 / 文字）
- 知识卡片与知识图谱（可编辑、可新增节点）
- 基于个人知识库的问答（带来源引用）
- 每日主动复习与反馈闭环
- 社区知识广场

## 说明
本原型为演示用途，Agent 问答、OCR 与语音为模拟实现；生产版本需接入 LLM、向量检索与数据服务。
